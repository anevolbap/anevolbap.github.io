Weekend Projects

Small things I build for fun.

  • Línea F: a map simulator for the planned Buenos Aires subway Line F.
  • Guía Abierta: a printable pocket guide to move around Buenos Aires by bus, subway and Ecobici, in the style of the classic Guía T. Built from open data.
  • Möbel: a to-scale floor-plan editor in the browser. Place rooms, doors and furniture, or let Rearrange propose new layouts. Try it.
  • org-rag: search over a personal notes vault (Org or Markdown) that follows the links between notes, not only text similarity. Comes with an Emacs frontend.
  • tidyrrr: tidies a messy music and movies drive from file tags, with a plan you read first and an undo. Nothing is deleted.
  • uvita: a Google Sheets script that gets the current UVA value (the inflation-indexed unit for Argentine mortgages).
  • bitaxe-health: a cron health check for a Bitaxe bitcoin miner, with ntfy alerts.
